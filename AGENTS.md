# Continuidade do projeto

- Ler AI_State.md antes de trabalhar e mantê-lo atualizado a cada marco.
- Fonte canônica: marmitero/tabuleiro, main. Usuário exige commit e push para preservar todo trabalho relevante; confirmar remoto após push.
- Documentação antes de arte; arte e sprites antes de implementação. Atualmente pré-produção visual; não criar código de jogo até finalizar assets previstos.
- Todo elemento artístico deve ser imagem gerada, inclusive FX/HUD; texto real e CSS de layout/acessibilidade são permitidos.
- Não confundir conceitos com sprites finais aprovados. Registrar prompts, origem, inspeção e status por imagem.
- Não configurar Vercel ou Supabase nesta fase local.
- Atualizar docs junto de alterações de regras. Não mudar a condição de vitória de cinco cristais globais sem aprovação.
